A simple Contact Management Web App built using Python and Gradio. It allows users to store, search, update, and delete contacts with persistent storage using a JSON file.

🚀 Features

Add new contacts

View all saved contacts

Search contacts by name or phone

Update contact details

Delete contacts

Data stored in JSON file

🛠 Technologies Used

Python

Gradio

JSON

▶️ How to Run

Install the required library:

pip install gradio

Run the Python script or notebook.

A local web interface will open where you can manage contacts.

📂 Project Files

contact_book.py or contact_book.ipynb – Main program

contacts.json – Stores contact data
